# WK Event Leads 1.4.1

Includes the shared Outreach release from 1.4.0 and an explicit site-local `WKEL_INSIGHTS_SITE_URL` setting. This allows Connect to report on the authorised Elite Nurse Partners public website while retaining its own WordPress leads and credentials. Search Console must match the configured reporting target; without this setting, the installation home URL remains the default. No public-site domain is hardcoded in plugin code.

Connect deployment uses dry-run only, with the server live flag false. CoFo and WK Digital have not been deployed.
